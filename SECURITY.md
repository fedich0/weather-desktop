# Безопасность и приватность

Статус: предварительная версия 0.9.0. Независимый аудит и нотариальная проверка Apple не проводились. Этот документ описывает исходный код, а не гарантирует отсутствие всех уязвимостей.

## Данные и разрешения

- `CGWindowListCopyWindowInfo` получает метаданные видимых окон. Код использует границы, идентификатор, уровень, непрозрачность и PID для исключения своих окон. Имена окон и их содержимое не сохраняются.
- Снимки экрана, содержимое документов, буфер обмена, камера, микрофон и ввод с клавиатуры других приложений не читаются.
- В приложении нет сетевого клиента, телеметрии, сервера, загрузчика обновлений или внешних исполняемых расширений.
- Настройки и один профиль сохраняются через NSUserDefaults в домене `local.windowsnow.desktop`. macOS может создавать стандартные служебные файлы состояния и диагностические отчёты.
- Приложение работает с обычными правами текущего пользователя. Скрипты не используют sudo. App Sandbox не включён: отсутствие сетевого кода не является системным запретом доступа к сети.
- В коде нет запроса Screen Recording, Accessibility или Full Disk Access. Доступность геометрии окон необходимо проверить на целевых версиях macOS. Не выдавайте дополнительные разрешения вслепую, если поведение отличается от описанного.

## Защита надёжности

Конечные значения и размеры проверяются перед симуляцией. Летящие частицы, осевшие листья и число окон ограничены. Геометрия заново выделяется при изменении ширины окна, в том числе дробном. При очистке накопления сбрасывается кэш отрисовки. Таймер приостанавливается для неактивного экрана/сессии.

Установка использует `~/Applications`, не требует sudo и не меняет Dock. Старый экземпляр этого приложения закрывается перед обновлением; прежняя установленная копия сохраняется внутри папки установщика (`build/installed-previous-…`). Внутренний домен настроек сохранён от имени WindowSnow.

Сборка создаёт временную `.app`, проверяет её локальную подпись и только затем заменяет предыдущую сборку с резервным копированием. Обычный workflow проверок имеет доступ на чтение к репозиторию. Отдельный workflow Prepare release draft запускается владельцем вручную и получает contents: write для создания черновика релиза. Публикация релиза автоматически не выполняется. Внешние actions закреплены по commit SHA. Секреты и сертификаты не нужны для тестов.

Проверки ASan/UBSan покрывают C++ ядро на тестовых сценариях. Они не доказывают безопасность AppKit, всех возможных входных данных или поставляемого бинарного файла.

## Сообщить о проблеме

После публикации владельцу репозитория следует включить GitHub Private vulnerability reporting. Если на вкладке Security доступна кнопка Report a vulnerability, используйте её для приватного отчёта. Включите версию, macOS, минимальные шаги и ожидаемый результат. Не прикладывайте пароли и личные документы.

Пока приватный канал не включён, не публикуйте подробности эксплуатации в открытом issue; запросите у владельца приватный контакт. Адрес для сообщений и сроки ответа ещё не установлены.

Сейчас сопровождение ориентировано на последний предварительный выпуск; гарантированного срока поддержки нет. Перед публичным стабильным релизом необходимы проверка на Mac и повторное ревью изменений.
