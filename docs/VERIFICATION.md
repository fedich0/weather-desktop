# Что проверено в 0.9.0 RC

Изменения 0.9.0 затрагивают иконку, оформление GitHub и подготовку черновика релиза; установка и упаковка унаследованы от 0.8.0. Физическое ядро не изменено относительно проверенной 0.7.0.

Дата подготовки: 2026-11-02. Среда: Linux, C++17, GCC. macOS SDK и настоящий рабочий стол Mac в этой среде недоступны.

| Проверка | Результат |
| --- | --- |
| Физика, столкновения, перекрытие окон, исчезновение окон, накопление | Пройдено: tests/physics.cpp |
| Скорость, ветер, накопление, переключение пола, осенние слои | Пройдено: tests/settings.cpp |
| NaN/Infinity, лимиты, массовое осыпание, плотность, дробный resize | Пройдено: tests/regressions.cpp |
| AddressSanitizer + UndefinedBehaviorSanitizer для этих тестов | Пройдено; LeakSanitizer отключён из-за ограничений среды |
| Синтаксис shell, структура plist, YAML, ICNS, целостность ZIP | Пройдено при упаковке 0.9.0 |
| Компиляция Objective-C++ / AppKit | Ожидает macOS |
| tests/AppSmoke.mm | Подготовлен; ожидает запуска на macOS |
| GitHub Actions и подготовка черновика релиза | YAML и shell-синтаксис проверены; workflows ещё не запущены |
| CPU, память, батарея, несколько экранов, Spaces | Ожидает измерений на Mac |
| Установка в ~/Applications и создание DMG | Скрипты подготовлены; ожидают Mac |
| Developer ID, notarization, Gatekeeper | Не выполнено |
| Независимый аудит безопасности | Не выполнен |

Команда локальной проверки ядра:

```bash
ASAN_OPTIONS=detect_leaks=0 SANITIZE=1 bash scripts/test.sh
```

В обычной среде начните с `SANITIZE=1 bash scripts/test.sh`, не отключая проверку утечек.

Ревью выявило и устранило: превышение лимита при осыпании листьев; непроверенные значения настроек и геометрии; устаревший кэш после сброса; несоответствие ширины массива при последовательных дробных resize; использование API ползунка без проверки macOS 12; безусловное восстановление произвольных ключей профиля; удаление предыдущей сборки при обновлении.

Просмотренный код не содержит сетевых запросов, аналитики, чтения пользовательских документов или повышения привилегий. Это вывод по исходникам в архиве, не результат мониторинга работающего Mac-приложения. Полнота визуальных эффектов и совместимость со всеми заявленными версиями macOS пока не установлены.

После запуска на Mac заполните: модель и чип, версия macOS/Xcode, commit, результаты CI, проверки из RELEASE.md, замеры нагрузки и обнаруженные ограничения. До этого версия остаётся release candidate.
