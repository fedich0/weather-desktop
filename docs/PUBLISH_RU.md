# Как выложить Weather Desktop на GitHub

1. Распакуй WeatherDesktop-Source.zip. Внутри — папка WeatherDesktop с README, src и остальными файлами.
2. Создай репозиторий `weather-desktop` в своём аккаунте и добавь **содержимое папки**, включая скрытую `.github`. Удобно делать это через GitHub Desktop: создать репозиторий из папки, commit, Publish repository. README должен находиться в корне репозитория.
3. Открой вкладку **Actions → Build and tests**. Дождись окончания. Если проверка упала, открой красный шаг и сохрани ошибку; пока сборка не прошла, готового приложения нет.
4. После успешного запуска открой его страницу и раздел **Artifacts**. Скачай один `local-test-*`: внутри будут ZIP с приложением, DMG и контрольные суммы. Для скачивания нужно войти в GitHub. DMG позволяет перетащить приложение в Applications без компиляции на компьютере получателя.
5. Проверь приложение на своём Mac по RELEASE.md. Для подготовки релиза выбери **Actions → Prepare release draft → Run workflow**, тег `v0.9.0-rc.1`. После успешных проверок появится **черновик prerelease** с файлами. Он автоматически не публикуется.

Сборки подписаны локально (ad-hoc), без Developer ID и notarization. Это ограничение указано в черновике релиза. Для полноценного распространения пройди шаги подписи из RELEASE.md.

В этой поставке выполнена подготовка исходников; GitHub Actions ещё не запускался и работа интерфейса на Mac не подтверждена. Поэтому используется обозначение release candidate, а не стабильный 1.0.

Не загружай build, dist, ключи и сертификаты. .gitignore уже настроен. Все файлы, нужные для разработки и публикации, находятся в исходном архиве; WeatherDesktop-Setup.zip предназначен для локальной установки.

Документация GitHub: https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts
