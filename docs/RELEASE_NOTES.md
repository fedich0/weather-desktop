## Weather Desktop — release candidate

Snow and autumn leaves for your macOS desktop, with window-edge accumulation, live preview, configurable glass controls and a cheerful new icon.

### Included

- Universal macOS application ZIP (Apple Silicon + Intel).
- DMG with an Applications shortcut for drag-and-drop installation.
- SHA-256 checksums.

### Before publishing this draft

- Confirm the current commit passed all required CI jobs and test it on a real Mac.
- Record the tested Mac models and macOS versions in these release notes.
- Review the manual checklist in docs/RELEASE.md.

**Signing status:** this automated build uses an ad-hoc signature. It is not Developer ID signed or notarized by Apple. Gatekeeper may block a downloaded test build. Do not disable system protection; use a trusted local source build or prepare a signed/notarized distribution as described in docs/RELEASE.md.

The minimum deployment target is macOS 11; full compatibility, energy usage and all display configurations are not yet verified. This is a prerelease, not a stable 1.0.
