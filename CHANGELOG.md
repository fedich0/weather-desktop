# Изменения

## 0.9.0 RC

- Новая жизнерадостная иконка: солнечный свет и голубой/персиковый градиент.
- Оформленный README для GitHub с иконкой, возможностями и инструкцией сборки.
- Ручной workflow создания черновика prerelease после тестов и упаковки.
- Шаблон отчёта об ошибке и краткая инструкция публикации.
- Удалены неиспользуемые фоны прежних итераций.
- Нативная сборка и проверка на Mac ещё не подтверждены.

## 0.8.0 beta

- Новое имя Weather Desktop и минималистичная иконка.
- Установка `.app` в пользовательскую папку Applications одним запуском Install.command.
- Повторный запуск установленного приложения не требует Terminal или исходников.
- Компактный установочный архив отдельно от исходного проекта.
- Создание DMG и универсального ZIP после сборки на Mac.
- Настройки сохраняются благодаря прежнему внутреннему bundle ID.
- Нативная сборка, установка и DMG ещё требуют проверки на Mac.

## 0.7.0 beta

- Ограничены массовые осыпания листьев, число поверхностей и накопленные листья.
- Добавлена обработка некорректных значений настроек, геометрии и шага времени.
- Исправлено изменение сетки столкновений при дробном изменении ширины окна.
- Исправлено обновление кэша накопления при очистке и повторном заполнении.
- Остановка таймера при выключении экрана и неактивной сессии.
- Предотвращение запуска второго обычного экземпляра приложения.
- Проверка доступности цветного трека ползунка на macOS 12+; уважение Reduce Transparency при построении интерфейса.
- Восстановление только известных числовых полей сохранённого профиля.
- Сборка в staging, резервная копия прежнего приложения, универсальная упаковка.
- Тесты C++ и сценарий проверки AppKit, CI, MIT, документация публикации и безопасности.

Статус проверки нативного интерфейса: ещё не запускался в среде подготовки этого архива.
